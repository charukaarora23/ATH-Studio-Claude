# Open-call style references

The user is giving 10 reference sets, one per style. Each style becomes a design sheet in
`site/post-studio/styles/style-NN.html`, built inside the ATH Social guide, then a template set in the studio.

## Style 01 · Specimen (references in `style-01/`, Nov 28 2026)
- `1.webp`, `2.png`: ROASTERS coffee packaging. Giant geometric sans letters used as the picture, rotated or bleeding off the edge. A rectangular mono spec label carries every fact as LABEL: VALUE rows. A small vertical text column and checkbox options (■ WHOLE BEAN / □ FILTER).
- `3.webp`: Lola Lab services. A serif index where each item has a small superscript number, items joined by slashes. Footer is "( Lola Lab ... Service )" in large serif parentheses, with a small caps line between them.
- `4.webp`: Fiverr tone-of-voice page. Large sans sentences with single words in serif italic, a few words underlined, circled numerals, a breadcrumb top left.
- `5.png`: "Raise the next generation of givers". A big serif headline on a flat colour with one word in a contrasting script, and a small sans paragraph at the bottom.

Built: `site/post-studio/styles/style-01.html` v2. The tilted label became a level fact panel (the guide bans stickers). Type is Inter Tight + Libre Baskerville only, on one White surface, laid out as the 7-slide launch sequence.

User feedback on v1: "terrible design sequence", told to use the ATH branding guidelines and not to abandon the style.
