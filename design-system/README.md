Arts to Hearts Project (ATH) is a global arts community and independent publisher. We run open calls, publish books and magazines, host a podcast and a prize, and build tools that help artists, curators and collectors meet. This system is the single source for how ATH looks, sounds and behaves everywhere: web, product, social, ads, email, print and books.

**Brand in one line:** *Merit, not network.* You don't need the right background, and you don't have to do it alone.

**Look in three words:** clean, bold, creative.

## The world we design in: Studio & Shelf
Every ATH piece is built from objects that live where art lives. On the artist side: the studio wall, sketchbooks, washi tape, polaroids, postage stamps and folder tabs. On the collector side: bookshelves, book spines, covers and certificates. Paint fields and film grain make it feel handmade; strict type and grids keep it premium.

| Object | Component | Meaning |
|---|---|---|
| Washi tape | `Tape` | An announcement pinned to the wall |
| Polaroid | `Polaroid` | An artist, seen |
| Postage stamp | `Stamp` | Art travelling the world |
| Sticker | `Sticker` | A price, a "new", a small celebration |
| Scalloped paper | `QuoteCard`, `ath-panel`, Footer | Handmade warmth, a personal note |
| Folder tab | `FolderTabs` | An artist's own files and progress |
| Book spine and cover | `BookTile`, `BookCover` | The outcome: your art on a shelf |

## Five design principles
1. **Loud headline, soft voice.** Every headline pairs Archivo Black (confidence) with Instrument Serif italic (warmth). "Get your art *on a bookshelf.*"
2. **The artist is the hero.** Real artwork and real names come first; ATH frames them, never competes.
3. **One focal pop.** Each layout gets one red moment (a sticker, a tape, one word). Never two.
4. **Paint behind, solid under text.** Paint fields carry emotion; text always sits on a solid colour or a scrim, never straight on paint.
5. **Honest and specific.** Real numbers, real deadlines, real prices. No hype, no fake urgency.

## How to use this system
- **Tokens** (Colours, Typography, Spacing tabs) are the only allowed values. Name them in specs: "`burgundy-500` on `cream-100`", "`poster-lg`".
- **Components** show every building block with live previews; each README gives exact specs and rules.
- **Assets**: logo, painted textures, and brand elements (tape, stickers, scallop edges, stamp frame) as SVG for Canva, Figma and print.
- **Sections** below: brand platform, voice, logo, colour, type, layout, elements, imagery, icons, motion, then one section per channel (social, ads, email, print), brand architecture, product UI, do's and don'ts, and the pre-flight checklist.
