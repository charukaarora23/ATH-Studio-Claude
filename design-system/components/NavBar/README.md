# NavBar

Top navigation for artstoheartsproject.com and the apply site.

## Anatomy
1. Announcement bar (optional): `surface-inverse` / `text-on-inverse`, Inter 13px 600. One sentence + one link. Only for a live call or launch.
2. Logo 56px (current wordmark badge), left.
3. Links: `ui-lg` (Inter 16/24, 500). Max 6. Active: 2px `accent` underline + `accent` text. Hover: 2px `cream-400` underline.
4. Right: "Sign in" link + one small primary button.

## Specs
Height 80px (padding `space-3` / `space-6`), `surface` background, hairline `border` bottom. Sticky on scroll. Mobile: logo + button + menu icon (24px).

## Link order (fixed)
Open calls · Books · Artists · Magazine · Podcast · (Shop).
