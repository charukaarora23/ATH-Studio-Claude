# Footer

Site footer on burgundy with a scalloped top edge.

## Anatomy
- Scallop top edge: `scallop-edge-burgundy.svg`, 24px pitch, bulging up into the page.
- Column 1 (wider, 1.6fr): brand line in Archivo Black 40/42 uppercase with an Instrument Serif italic phrase in `peony`, then the newsletter field + inverse button.
- Columns 2 to 4: headings `overline` in `peony`; links Inter 14/20 in `cream-100`.
- Legal row: Inter 12px `burgundy-100`, hairline rule above at 25% cream.

## Specs
Padding `space-12` / `space-8` / `space-6`. Grid gap `space-8`. Mobile: one column, brand line first.
