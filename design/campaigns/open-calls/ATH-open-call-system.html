Arts to Hearts · Open calls

One system for every open call.

Built from three things: the 13 references you sent, your Instagram, and your ads. Every call uses the same four colours, the same type and the same frame. A call changes only its artwork and its words, so the feed stays recognisable while each post still looks different.

1 · What you like

What your 13 references have in common

A fixed palette

Every reference brand uses the same 3 or 4 colours on every post: one dark, one hot accent, one soft light. None changes colour from post to post. Two of them are ink, orange and peach, which are already ATH colours.

Big grotesk, serif italic accent

Large, tight sans-serif headlines with one phrase in serif italic. A clean look rather than a decorative one.

One device per slide

A receipt, a chat, an IN/OUT list, a big number, a search bar. Each slide makes one point in one picture.

Interface details

Pills with arrows, small bracket labels in the corners, rounded image frames and an outlined Swipe button. They read as a product, not a flyer.

Photo inside a frame

The image sits in a rounded frame or a clean split. Text sits on colour, not on the photo, so it's always readable.

One hand-drawn mark

A circle or underline on the one word that matters. Used once, never as decoration.

3 · The system

Four colours. Always the same.

InkCovers, awards. The dark.

Blood orangeStats, the close, the keyword pill. The hot accent.

PeonyValue and questions. The soft light.

CreamLists, text, receipt paper.

All four are ATH brand colours. Each slide type always gets the same colour, so a call's carousel always runs ink, orange, peony, ink, cream, peony, orange.

PartRule
TypeInter Display Medium for headlines, set tight, with one phrase in Instrument Serif italic. Inter for everything else. No third font.
FrameThe same on every slide: bracket label at top left, series name at top right, logo at bottom left, an outlined arrow pill at bottom right.
Cover[OPEN CALL] label → "Calling all ___ artists" hook → art in a rounded frame → "Get published… Win $500" → orange Comment KEYWORD pill → deadline.
SlidesChoose from seven devices: stat, receipt, prize, IN/OUT, chat, steps, close. One device per slide.
KeywordOne word per call (GARDEN, AWARD, FUND), used on the cover, the close, the caption, stories and the DM.
ArtworkAlways inside a frame, always credited. No overlays or shapes on artists' work.
